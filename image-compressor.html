How "same quality" is guaranteed

  • Lossless mode first strips EXIF, GPS, XMP, embedded thumbnails and text chunks — the compressed pixel data is never touched — then also tries PNG and lossless WebP, comparing every pixel of the result against the source. A file is only accepted if all pixels match exactly — otherwise your original is kept untouched.
  • Visually identical / High / Balanced run a binary search over encoder quality and score each candidate with SSIM (structural similarity) against the original. The smallest file that stays above the threshold wins, and the measured score is shown on every card.
  • Everything happens locally with the Canvas API — no server, no network request, no account. You can open this file offline or host it anywhere.

* Formats are decoded by your browser, so exotic inputs (TIFF, HEIC) depend on OS support — Safari opens HEIC, Chrome generally does not. AVIF output is only offered when the browser can encode it. Animated GIF/WebP are reduced to their first frame.
